
# Real user questions: AquiferAsk

Written the way my user types them. User: Panchayat engineer in a water-stressed block of Ramanathapuram planning recharge structures.

These 10 questions become my first evaluation set in Week 3. Question 6 is not answerable from my documents: the product must say "I don't know".
